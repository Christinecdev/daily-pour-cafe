# The Daily Pour Cafe 🍵

## Live Demo

https://github.com/Christinecdev/daily-pour-cafe.git

A fictional café website built with HTML5 and CSS3 as part of my web front-end web development journey through FreeCodeCamp.

## Overview

The Daily Pour Café is a multi-page website designed to showcase a welcoming coffee shop experience. The project focuses on clean semantic HTML, organized CSS, and a consistent design across multiple pages.

## Features

* Multi-page Website
* Home, Menu, and a Business Card
* Semantic HTML5 structure
* Shared CSS stylesheet
* Organized project structure
* Café branding and imagery
